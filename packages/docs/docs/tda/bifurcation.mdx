# Bifurcation Sweep

## Method

We sweep the perturbation amplitude $A$ from 0 (smooth disk) to 0.3 (transitional disk) in steps of 0.05, running 1000 systems at each value. All other parameters are held fixed ($\gamma = 1.0$, $c_\text{migI} = 0$, seed = 42).

This directly addresses Phase D of the project proposal: **does the smooth-to-transitional disk transition produce a topological bifurcation in the planetary architecture space?**

The seven runs are listed in the [run log](../simulations/runs).

## Interpretation

### $H_1$: non-monotonic degeneracy structure

The number of persistent $H_1$ loops does not decrease monotonically with $A$. Instead, it oscillates:

$$
3 \to 4 \to 1 \to 0 \to 2 \to 0 \to 2
$$

This is **more complex than a simple phase transition**. Two regimes are visible:

1. **Degeneracy creation** ($A = 0 \to 0.05$): a small perturbation _increases_ the number of loops from 3 to 4. The density modulation introduces new formation pathways that create additional degeneracies in the inverse problem -- distinct disk configurations that produce architecturally similar systems.

2. **Degeneracy resolution** ($A = 0.1 \to 0.15$): at moderate perturbation amplitudes, loops die. At $A = 0.15$ and $A = 0.25$, all persistent $H_1$ features vanish ($\beta_1 = 0$). The perturbation provides enough additional information to fully resolve the inverse problem at these amplitudes.

3. **Degeneracy recurrence** ($A = 0.2, 0.3$): loops reappear at higher amplitudes. New formation channels created by stronger perturbations introduce fresh degeneracies.

The oscillatory pattern is consistent with the **cosine structure** of the density perturbation (Eq. 1.1 of Chaparro Molano et al. 2019):

$$
\Sigma_p(r) = \Sigma(r)\left[1 + A\cos\left(\frac{2\pi r}{f\,H(r)}\right)\right]
$$

As $A$ increases, the radial positions of over-dense and under-dense regions create alternating conditions for planet formation, producing a non-monotonic effect on the topology of the outcome space.

### $H_0$: cluster structure varies

The $H_0$ max lifetime and gap between the first and second lifetimes also vary non-monotonically:

- At $A = 0$ and $A = 0.25$, there is a **dominant single cluster gap** (large gap between 1st and 2nd lifetimes), indicating a sharp binary split between giant and terrestrial systems.
- At $A = 0.05$, $A = 0.15$, and $A = 0.3$, the gap is small ($< 0.2$), indicating that the cluster structure is more **graded** -- the transition between formation channels is smoother.
- At $A = 0.25$, the maximum $H_0$ lifetime reaches 6.18, the highest across all runs, suggesting the strongest cluster separation occurs at this perturbation amplitude.

### Key finding

The perturbation amplitude $A$ acts as a **bifurcation parameter** for the topology of the planetary architecture space, but the bifurcation is not a simple threshold crossing. Instead, the topology oscillates as $A$ increases, with:

- Two windows where all degeneracies are resolved ($A \approx 0.15$ and $A \approx 0.25$)
- Intermediate values where new degeneracies are created

This oscillatory behavior was **not predicted** by the original analysis and would be invisible to any method that treats $A$ as producing a monotonic effect on the population. It is a direct consequence of the radial structure of the perturbation interacting with the characteristic scales of planet formation (snow line, isolation mass, migration timescales).

## Next steps

1. **Finer sampling** around $A = 0.15$ and $A = 0.25$ to sharpen the resolution windows.
2. **Fiber analysis** at the degeneracy-free points: verify that $F^{-1}(y)$ is connected when $\beta_1 = 0$.
3. **Vary the perturbation length scale** $f$ as a second bifurcation parameter, building a 2D bifurcation diagram in $(A, f)$ space.
